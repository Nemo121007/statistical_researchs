# Новый детектор в example_model.ipynb

Аргументы (в Claude Code — `$ARGUMENTS`, в OpenCode — из команды или запроса пользователя): название метода и, если есть, источник (статья из `docs/papers/`, описание).

Правила, которые соблюдаются целиком: `AGENTS.md` (стиль кода, согласование, журнал) и `notebooks/AGENTS.md`
(оформление блокнота, markdown моделей, метрики test, вывод ячейки, порог).

## 1. Уточнить метод

До написания кода должны быть ясны: что считается score точки и в какую сторону (больше — аномальнее);
на чём учится модель (весь train или только move); гиперпараметры и их значения; нужны ли окна
(тогда общие `N_WINDOWS`, `TORCH_*` и хелперы окон из общей ячейки). Если чего-то нет в аргументах и в статье —
спросить пользователя одним вопросом со всеми пунктами, не додумывать.

Выбрать:
- название для сводки (`Isolation Forest`, `LSTM-автоэнкодер`, …);
- `slug` — префикс переменных и id ячеек, латиница в нижнем регистре (`lof`, `ocsvm`);
- `PREFIX` — префикс констант модели, верхний регистр (`LOF`, `OCSVM`).

Проверить через `grep -n` по блокноту, что `slug`, `<slug>_summary` и `PREFIX_` ещё не заняты.

## 2. Посмотреть образец

Блок ARIMA — ячейки `arima-theory-md` и `arima-code-cell`:
`grep -n '"id": "arima-' notebooks/example_model.ipynb`, затем `sed -n` по найденному диапазону.
Общие хелперы — в ячейке с `def trajectory_series_pair`; не дублировать их в ячейке модели.

## 3. Написать markdown-ячейку

Структура как у ARIMA:

```
## <Название метода>

### Постановка
<идея метода в 1–2 абзацах>

### Модель и score
<формулы в $…$ и $$…$$; явное определение score s_i и правила \hat a_i = 1[s_i > τ]>

### Обучение и порог
Порог τ выбирается только на train по квантилям {s_i}: максимум MCC; в полосе MCC_BAND — минимальный
операционный distance loss. На test применяется тот же τ без подгонки. Сценарии df1 и df2 — доли обучения
TEST_SPLIT_1 и TEST_SPLIT_2.
```

Без inline-кода в обратных кавычках и без декоративного полужирного; полужирным — только **move** /
**anomaly** там, где задаётся положительный класс. Если метод отступает от схемы порога (как DBSCAN,
One-Class SVM, MPCT), — описать отступление в «Обучение и порог».

## 4. Написать code-ячейку

Взять `.claude/skills/new-detector/code_template.py`, подставить `{{PREFIX}}`, `{{slug}}`, `{{TITLE}}`, реализовать
`{{slug}}_fit` и `{{slug}}_scores` (или нужное число функций модели), убрать комментарии шаблона.

- Константы модели — в начале ячейки, без повторных объявлений.
- Функции и классы, нужные только этой модели, — в этой ячейке перед циклом сценариев.
- Стиль кода — раздел «Стиль кода» в `AGENTS.md`: аннотации, Google docstrings, ``аргументы`` в тексте,
  суффиксы единиц, векторизация, black, строка до 120 символов.
- Новый сторонний пакет: импорт — в ячейку импортов (через `grep -n` / `sed -i` по правилам больших блокнотов),
  пакет — в `requirements.txt` и `pyproject.toml`; установку в `.venv` — только после вопроса.

## 5. Вставить в блокнот

Тексты ячеек — во временные файлы в scratchpad, затем из корня проекта:

```bash
.venv/bin/python .claude/skills/new-detector/insert_cells.py notebooks/example_model.ipynb \
  --slug <slug> --title "<Название>" --markdown <файл.md> --code <файл.py>
```

Скрипт вставляет `<slug>-theory-md` и `<slug>-code-cell` перед общей сводкой (`master-summary-md`),
добавляет `("<Название>", "<slug>_summary")` в конец `_model_summary_catalog`, сохраняет форматирование
и CRLF и отказывается работать, если id заняты или формат файла не воспроизводится. После вставки —
удалить временные файлы и проверить `python -m json.tool notebooks/example_model.ipynb > /dev/null`.

## 6. Проверить и записать

- Предложить прогон `/run-notebook example_model.ipynb`; сам полный прогон — только после согласия.
  Ячейка новой модели должна пройти, `<slug>_summary` — появиться в общей сводке.
- Запись в `change.log`: блок `## <дата> — Детектор <Название>`, строки по файлам.
- `report/Отчёт.tex` и `docs/notes/methods.md` не трогать, пока пользователь явно не подтвердит,
  что модель готова (раздел «Завершение работы над моделью» в `notebooks/AGENTS.md`).
