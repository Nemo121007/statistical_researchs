# Прогон блокнота в памяти

Аргументы (в Claude Code — `$ARGUMENTS`, в OpenCode — из команды или запроса пользователя): имя блокнота в `notebooks/` (например, `example_model.ipynb`), опционально
`--stop-on-error`.

Если скилл вызывается не пользователем, а по решению агента, — сначала спросить разрешение на полный прогон
(правило «Согласование действий» в `AGENTS.md`).

## Запуск

Из каталога `notebooks/` (там же ожидаются данные `../data/test.csv`):

```bash
cd notebooks && MPLBACKEND=Agg PYTHONWARNINGS=ignore \
  ../.venv/bin/python ../.claude/skills/run-notebook/run_notebook.py <блокнот.ipynb> [--stop-on-error]
```

Долгий прогон (`example_model.ipynb` — около 1,5 мин) запускать в фоне и дождаться уведомления.

Скрипт `run_notebook.py`:
- выполняет code-ячейки по порядку в одном `InteractiveShell`, корень проекта — в `sys.path`;
- отключает переключение GUI, иначе `%matplotlib inline` обрывает ячейку импортов;
- выходы в `.ipynb` не пишет;
- печатает выводы ячеек, по строке статуса на ячейку (индекс, время, ok/FAIL, первая строка кода), для упавших —
  трейсбек и строку `error`, в конце — общую строку `TOTAL ... failed cells: [...]`;
- код выхода 1, если упала хоть одна ячейка.

## Отчёт

Коротко: сколько ячеек, сколько прошло, общее время; по каждой упавшей — ячейка, модель, ошибка и вероятная
причина. Различать ошибку блокнота и ошибку окружения или запуска. Выводы о качестве моделей на синтетическом
`test.csv` не делать.
