# План переписывания Отчёт.tex

Рабочий план приведения `report/Отчёт.tex` к согласованным правилам. Правила стиля — скилл `report`
(`.claude/skills/report/SKILL.md`), обозначения и термины — `report/glossary.md`. План составлен 2026-10-29,
к правке отчёта ещё не приступали.

Порядок работы: по одному этапу за раз; после этапа — показать пользователю изменения, запись в `change.log`,
отметить пункты здесь (`[x]`). Правка отчёта — только после подтверждения пользователя на каждый этап.
Номера строк ниже — на момент составления плана; перед правкой искать по тексту.

## Этап 1. Оформление (механическая правка, смысл не меняется)

- [ ] Нумерация: все `\subsection*`, `\subsubsection*` → с номерами; убрать ручные номера «1. … 7.» в заголовках
      раздела «Разбор результатов, ревью и выводы».
- [ ] `\textbf{Формализация}:\\` и `\textbf{Обучение и пороговое значение}:\\` → `\paragraph{Формализация}`,
      `\paragraph{Обучение и выбор порога}`.
- [ ] Тире «—» → `---`.
- [ ] `$$ … $$` → `\[ … \]`.
- [ ] Ручные `\\` в тексте → абзацы пустой строкой (в таблицах и формулах оставить).
- [ ] Десятичная запятая `0{,}6`, `0{,}845` → точка; разряды — `\,`.
- [ ] «сек.» → «с»; числа в тексте — 3 знака для долей, округление расстояний.
- [ ] Черновые пометки «(\textit{необходимо предоставить корреляционный анализ?})», строки ~220 и ~223 →
      `\todo{…}`; в преамбулу — `\newcommand{\todo}[1]{\textcolor{red}{[#1]}}` (пакет `color` уже подключён).
- [ ] Подписи столбцов итоговых таблиц → русские по глоссарию, двухуровневая шапка «Задержка, с» и «Эпизоды».
- [ ] df1 / df2 в тексте и подписях → «сценарий $\rho=0.6$» / «сценарий $\rho=0.8$».

## Этап 2. Обозначения и термины по глоссарию

- [ ] Плоские координаты: $x_i$, $y_i$ (как координата), $E_i$, $N_i$ вне определения ENU → $o_i$, $n_i$;
      $\Delta x$, $\Delta y$ → $\Delta o$, $\Delta n$ (признаки DBSCAN, LOF, Isolation Forest, Robust PCA;
      строка ~258 `x_i \equiv E_i, y_i \equiv N_i`).
- [ ] Ускорение $a_i$ (HMM, DBSCAN, LOF, IF) → $a^{\mathrm{acc}}_i$.
- [ ] Время: `time_i` / `\mathit{time}_i` → $t_i$ после постановки задачи (в постановке — единообразно).
- [ ] Англицизмы в тексте → русские термины с английским в скобках при первом упоминании: train/test,
      score, Distance loss, Detection Delay, on-time, late/missed, precision/recall и др.
- [ ] «опорная точка» для ENU → «начало координат ENU»; для GP — «опорные точки».
- [ ] «хорда» → «звено»; «режим» как синоним эпизода → «эпизод аномалии»; «трек» → «ряд» или «траектория».
- [ ] Имена констант блокнота в тексте (AR\_LAGS, HAMPEL\_HALF\_WINDOW и т. п.) → значения или словесное описание.
- [ ] «по score (функции правдоподобия)», строка ~338 → «по оценке аномальности».
