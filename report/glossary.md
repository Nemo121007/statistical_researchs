# Глоссарий: обозначения и термины

Единый словарь для `report/Отчёт.tex`, markdown-ячеек блокнотов и `docs/notes/`. Любое новое или изменённое
обозначение или термин заносится сюда в том же задании, где оно появилось в тексте.

## Обозначения

| Обозначение | Смысл | Единицы | В коде |
| --- | --- | --- | --- |
| $i$ | индекс точки ряда после предобработки, $i=0,\ldots,N-1$ | — | индекс строки `frame` |
| $t_i$ | время точки | с | `time` (через `time_to_seconds`) |
| $\varphi_i$, $\lambda_i$ | широта и долгота WGS-84 (в постановке задачи — $\mathit{lat}_i$, $\mathit{lon}_i$) | градусы | `lat`, `lon` |
| $o_i$ | плоская координата на восток (ost) в локальной системе ENU, компонента $E$ | м | `x` |
| $n_i$ | плоская координата на север (nord) в локальной системе ENU, компонента $N$ | м | `n` |
| $y_i$ | эталонная метка точки: $\mathrm{move}$ или $\mathrm{anomaly}$ | — | `y`; числовая `label`: anomaly → 0, move → 1 |
| $\hat y_i$ | метка, предсказанная моделью | — | маска `predicted_anomaly` |
| $a_i$, $\hat a_i$ | бинарные индикаторы аномалии: $a_i=\mathbf{1}[y_i=\mathrm{anomaly}]$, $\hat a_i=\mathbf{1}[\hat y_i=\mathrm{anomaly}]$ | — | `anomaly_mask` |
| $s_i$ | score точки: чем больше, тем аномальнее | зависит от модели | `*_scores` |
| $\tau$ | порог по score: $\hat a_i=\mathbf{1}[s_i>\tau]$ | как у $s_i$ | `selection["tau"]` |
| $\rho$ | доля обучающей части ряда в сценарии | — | `TEST_SPLIT_1`, `TEST_SPLIT_2` |
| $(\varphi_0,\lambda_0)$ | начало координат ENU | градусы | первая точка ряда или выборки |
| $v_i$ | скорость | м/с | кинематика в `trajectory_kinematics` |
| $a^{\mathrm{acc}}_i$ | ускорение | м/с² | то же |
| $\Delta\psi_i$ | приращение курса | рад | то же |
| $d_i$ | отклонение в плоскости ENU между заполненными траекториями | м | `pointwise_deviations_m` |

Правила:

- Буква $y$ — только метка; для плоских координат — только $o$ и $n$ (не $x$, $y$, $E$, $N$ вне определения ENU).
- Приращения — $\Delta o_i$, $\Delta n_i$.
- Буква $a$ без индекса — только индикатор аномалии; ускорение — $a^{\mathrm{acc}}_i$.
- В коде столбец восточной координаты пока называется `x`; соответствие фиксируется в колонке «В коде».

## Термины

Общее правило: в тексте используется русский термин; при первом упоминании в документе после него в скобках
даётся английский эквивалент, если он есть, — «обучающая выборка (train)». Дальше — только русский термин.
Латинские имена классов в формулах — $\mathrm{move}$, $\mathrm{anomaly}$.

### Данные и разметка

| Термин | Английский | Значение | Не использовать |
| --- | --- | --- | --- |
| ряд | time series | последовательность точек во времени (данные) | трек |
| траектория | trajectory | геометрическая линия по точкам ряда — для геометрических метрик и карт | трек |
| запись | record | строка исходного CSV до предобработки | — |
| точка | point | элемент ряда после предобработки | наблюдение |
| штатный ход | move | класс точек с нормальным движением судна | штатное движение, норма |
| аномалия | anomaly | класс точек с аномальным движением; аномальная точка — точка с меткой anomaly; помехи GPS — физическая причина, не название класса | — |
| эпизод аномалии | anomaly episode | максимальный непрерывный участок точек с эталонной меткой anomaly | — |
| отрезок | segment | непрерывный участок точек одного класса (HMM, окна) | — |
| режим | regime, state | только скрытое состояние HMM | режим как синоним эпизода |
| эталонная разметка | ground truth | ручная разметка специалиста, $y_i$ | истинные метки |
| предсказание | prediction | разметка, выданная моделью, $\hat y_i$ | — |
| разрыв по времени | time gap | интервал между соседними точками больше порога (сейчас 180 с) | пауза, пауза связи |

### Обучение и проверка

| Термин | Английский | Значение | Не использовать |
| --- | --- | --- | --- |
| обучающая выборка | train | начальная часть ряда до границы разбиения; выборки — части одного ряда, а не независимые | train, обучение, тест в тексте |
| тестовая выборка | test | конечная часть ряда после границы разбиения | test в тексте |
| сценарий | scenario | разбиение ряда с долей обучения $\rho$: «сценарий $\rho=0.6$», «сценарий $\rho=0.8$» | df1, df2 (только имена переменных в блокноте) |
| метод | method | алгоритм в общем виде, как в источнике | — |
| детектор | detector | реализация метода в блокноте, выдающая разметку | — |
| модель | model | обученный детектор с конкретными параметрами | модель как синоним метода |

### Модели, оценка аномальности и порог

| Термин | Английский | Значение | Не использовать |
| --- | --- | --- | --- |
| оценка аномальности | anomaly score | число $s_i$ на точку: чем больше, тем аномальнее | score в тексте; функция правдоподобия как общее название |
| порог | threshold | $\tau$; решение $\hat a_i=\mathbf{1}[s_i>\tau]$ | пороговое значение (кроме заголовка «Обучение и выбор порога») |
| полоса MCC | MCC band | кандидаты-пороги, у которых MCC на обучающей выборке отстаёт от лучшего не больше заданной величины (сейчас 0.02) | имя константы MCC_BAND в тексте |
| подбор | selection | выбор порога или гиперпараметров на обучающей выборке; на тестовой — «без подбора» | подгонка |
| сетка кандидатов | grid candidate | набор проверяемых значений; для порога — квантили оценки аномальности на обучающей выборке | — |
| параметры | parameters | оцениваются по данным (веса, коэффициенты) | — |
| гиперпараметры | hyperparameters | задаются заранее или подбираются по сетке кандидатов (размер окна, $\nu$, $\varepsilon$) | — |
| причинный | causal | решение в точке $i$ использует только точки до $i$ включительно | каузальный, онлайн |
| пакетный | batch | решение использует весь ряд, в том числе будущие точки | — |
| одношаговый прогноз | one-step forecast | прогноз точки $i$ по точкам до $i-1$; «уровень» — только в AR и ARIMA (уровень ряда против приращения) | — |
| признаки | features | вектор $\mathbf f_i$ величин, вычисленных по точке и её соседям; кинематические признаки — скорость, ускорение, приращение курса | кинематический вектор |
| робастная нормировка | robust scaling | $(\mathbf f_i-m)/\mathrm{IQR}$, $m$ — медиана, IQR — межквартильный размах, оба по точкам штатного хода обучающей выборки | робастная шкала, шкала |
| якорь | anchor | последняя принятая точка штатного хода в MPCT; только у этого метода | — |
| инновация | innovation | $\mathbf r_i$ — разность измерения и прогноза фильтра | — |
| квадрат нормированной инновации | normalized innovation squared, NIS | $\mathbf r_i^\top S_i^{-1}\mathbf r_i$ | нормированная инновация |

### Метрики

Все расстояния и длины в метриках считаются в плоскости ENU (евклидово расстояние по $o$, $n$), а не геодезически.

| Термин | Английский | Значение | Не использовать |
| --- | --- | --- | --- |
| заполненная траектория | filled trajectory | траектория, в которой аномальные точки заменены линейной интерполяцией по времени между соседними точками штатного хода | — |
| отклонение | deviation | $d_i$ — расстояние в плоскости ENU между точками заполненных эталонной и предсказанной траекторий в момент $t_i$; опорная точка ENU — первая точка заполненной эталонной траектории оцениваемой выборки | геодезическое отклонение |
| среднеквадратичное отклонение | RMSE | по точкам с $d_i>0$ | — |
| максимальное отклонение | maximum deviation | $\max d_i$ в формулах и таблицах | Max($d_i$) |
| ошибка длины траектории | distance loss, DL | $\lvert L_{\mathrm{pred}}-L_{\mathrm{ref}}\rvert$, $L$ — сумма длин звеньев заполненной траектории в ENU; DL — в формулах и таблицах | distance loss в тексте |
| операционная ошибка длины | operational distance loss | критерий подбора порога на обучающей выборке: длина ломаной только по принятым точкам в ENU ряда, без интерполяции; не путать с DL | операционный DL |
| принятая точка | accepted point | точка, которую модель отнесла к штатному ходу | — |
| отвергнутая точка | rejected point | точка, которую модель отнесла к аномалии | — |
| ломаная | polyline | траектория, соединяющая принятые точки | — |
| звено | segment | отрезок ломаной или траектории между соседними точками | хорда |
| задержка обнаружения | detection delay | время от начала эпизода аномалии до первой его точки, отнесённой моделью к аномалии; агрегаты — медиана, среднее, 95-й перцентиль, максимум | Delay в тексте |
| своевременное обнаружение | on-time | аномалия найдена в первой точке эпизода; счётчик — число своевременных эпизодов | — |
| опоздание | late | аномалия найдена позже первой точки эпизода | — |
| пропуск | missed | внутри эпизода аномалия не найдена; счётчик — число опозданий и пропусков | — |
| точность | precision | доля верных среди точек, отнесённых к аномалии | — |
| полнота | recall | доля найденных среди эталонных аномальных точек | — |
| F1-мера | F1 | гармоническое среднее точности и полноты | — |
| коэффициент корреляции Мэттьюса | MCC | главный критерий подбора порога на обучающей выборке; в итоговых таблицах на тестовой выборке не показывается | — |
| положительный класс | positive class | аномалия; TP, FP, FN, TN — истинно и ложно положительные, ложно и истинно отрицательные точки | — |

### Координаты, окна и геометрия

| Термин | Английский | Значение | Не использовать |
| --- | --- | --- | --- |
| система ENU | East–North–Up | локальная прямоугольная система координат в метрах; WGS-84 и ECEF — без перевода | — |
| плоскость ENU | ENU plane | горизонтальная часть системы ENU, координаты $(o,n)$; компонента U отбрасывается | горизонтальная проекция |
| начало координат ENU | origin | точка, от которой отсчитываются $o$, $n$ | опорная точка (для ENU) |
| опорные точки | support points | подвыборка, на которой строятся гауссовский процесс и GP-EKF | опора |
| окно | window | фиксированное число подряд идущих точек без разрыва по времени внутри | — |
| длина окна | window length | число точек в окне | — |
| шаг окон | stride | сдвиг между началами соседних окон | старт окна |
| агрегация по окнам | window aggregation | оценка аномальности точки — максимум оценок окон, которые её накрывают | — |
| относительные координаты окна | relative window coordinates | $(o,n)$ точек окна за вычетом первой точки окна, км | положение относительно начала окна |
| индекс формы | shape index | отношение длины пути по окну к смещению между первой и последней точками; $\ge 1$, больше — извилистее | форма окна, shape в тексте |
| скорость | speed | $v_i$ | — |
| ускорение | acceleration | $a^{\mathrm{acc}}_i$ | скоростное ускорение |
| приращение курса | heading change | $\Delta\psi_i$ | — |
| ошибка реконструкции | reconstruction error | разность окна и его восстановления автоэнкодером | ошибка восстановления |
| калибровка | calibration | оценка среднего и дисперсии ошибки по окнам штатного хода обучающей выборки для нормировки оценки аномальности | — |
| подвыборка | subsample | случайная часть точек штатного хода ограниченного размера; на ней обучается One-Class SVM | опора |
