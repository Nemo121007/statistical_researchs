# statistical_researchs — инструкции для агента

Исследование: детекция аномалий в GPS-телеметрии судов. Метка 0 — anomaly
(положительный класс), значение больше нуля — move.

## Рабочая директория

- Всегда работай с основными файлами проекта в, а не с копиями в отдельных worktree OpenCode.
- Если текущая сессия открыта в worktree, правки всё равно вноси в основной каталог и коммить туда, чтобы изменения сразу появлялись в сторонней IDE.

## Коммиты

- Коммитить только по явной команде пользователя. Без такой команды изменения остаются в рабочем дереве.
- В сообщении коммита указывать содержимое изменений: что сделано, какие файлы,
  разделы, функции или поведение затронуты. Формулировка должна быть
  понятной без открытия diff, а не «Фиксация файлов».

## Инструменты

- Предпочитай встроенные инструменты (`read`, `grep`, `glob`, `edit`, `write`) вместо `shell`. 
- Для поиска по коду/файлам используй `grep` и `glob`, для чтения — `read`. 
- Для правок — `edit` (или `write` для полного перезаписывания). 
- Не используй однострочники `python -c`, `jq`, `node -e` и прочие shell-команды для разбора JSON, `.ipynb`, CSV, текста. Весь нужный контекст можно получить через `read`/`grep`.
- `shell` оставь только для того, что действительно нельзя сделать встроенными инструментами: запуск скриптов/тестов, git-операции, работа с окружением.

## Канон

- Источник истины: `notebooks/example_model.ipynb` и `report/Отчёт.tex`.
- `docs/notes/results.md` и `notebooks/example_model_1/2.ipynb` — архив прошлых
  прогонов (другой размер выборки, другой набор моделей), не эталон.
- Правила оформления блокнотов — `notebooks/AGENTS.md`.

## Эксперименты

- Блокноты запускаются с рабочей директорией `notebooks/`, данные ожидаются
  в `../data/2.csv`.
- Новый детектор повторяет структуру блока ARIMA в `example_model.ipynb`.
- Порог: максимум MCC на train, затем полоса `MCC_BAND`, затем минимальный
  операционный distance loss; на test переносится тот же порог без подгонки.

## Окружение

- Python 3.12, виртуальное окружение `.venv`.
- Полный список зависимостей — `requirements.txt`. `pyproject.toml` отстаёт:
  в нём нет `pyro-ppl`, `statsmodels`, `hmmlearn`, `Pillow`.
- `data/*.csv` не хранятся в git: без исходных файлов эксперименты
  не воспроизводятся.
